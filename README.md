# movix
![GitHub Release](https://img.shields.io/github/v/release/mongomangoCZcz/movix)<br>
aplikace pro android a android tv která pomocí webshare přehrává filmy a seriály (je potřeba mít účet VIP webshare)
<br><p style="color: red;">brzy bude dostupné také pro IOS !!!<p>
# funkce
<li>Přehrávaní obsahu (filmy a seriály)</li>
<li>Stahování obsahu do telefonu (film a seriály)</li>
<li>Pokračovat ve sledování (umožnuje pokračovat přesně tam kde jste skončili) zatím pouze pro android!!!</li>
